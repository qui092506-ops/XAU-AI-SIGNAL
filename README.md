# XAU KATANA V1

Static, mobile-responsive XAUUSD simulated signal dashboard.

## Deploy
Upload these files to a GitHub repository and import the repository into Vercel.

No environment variables are required for V1.

## Included
- XAUUSD simulated price
- BUY / SELL simulated signals
- Entry / SL / TP1 / TP2
- Signal strength
- Primary trade setup
- Analysis reasons
- Signal history
- Mobile responsive UI
- Browser-side simulation only

IMPORTANT: This version uses simulated data and is not a live trading system.
