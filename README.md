# XAU KATANA V2

XAUUSD dashboard with a public spot-price feed.

## V2 changes
- XAU/USD spot price is fetched from XAUS.
- Client refresh is about every 30 seconds.
- Feed status is shown as LIVE / STALE / ERROR.
- Signal generation is still simulated.
- Primary Trade Setup and Signal History remain available.
- Mobile responsive.

## Deploy
Upload `index.html`, `style.css`, and `script.js` to the GitHub repository and let Vercel redeploy.

## Important
The displayed market price is an indicative XAU/USD spot feed, not a broker execution price.
The BUY/SELL signal is simulated and is not a live trading strategy.
